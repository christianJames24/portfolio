# HTML Portfolio

This is my first year HTML/CSS portfolio project.  
It has a bunch of pages I made to practice building websites and organizing content.

## What's in here
- **index.html** → the welcome page with links to everything else
- **home.html** → a short intro about me
- **work.html** → assignments I’ve done (like Success Airlines, Bean’s Beans, etc.)
- **program.html** → why I chose my program
- **comic.html** → a fun page about comics I make
- **portfolio.html** → explanation of the site design and choices
- **websites.html** → websites I like and don’t like
- **wireframes.html** → screenshots of the wireframes for each page
- **style3.css** → the stylesheet for the whole site
- **Images/** → all the pictures and assets
- **WEBSITE LINKS.txt** → list of links to the hosted site
